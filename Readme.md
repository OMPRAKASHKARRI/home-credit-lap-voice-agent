# Home Credit — Loan Against Property AI Voice Agent

## Project Overview
A conversational AI voice agent built using Retell AI to conduct preliminary Loan Against Property (LAP) eligibility checks for existing Home Credit customers.

## Agent Details
- **Agent name:** Priya
- **Company:** Home Credit
- **Maximum offer amount:** ₹75 lakh
- **Platform:** Retell AI

## Key Features
- Customer identity confirmation and availability check
- Property type and ownership verification
- Original property document availability check
- Loan amount validation against the ₹75 lakh limit
- Employment type and income mode verification
- Property market value and loan tenure collection
- Disqualification handling for ineligible cases
- Routing for existing property loans or EMI reduction requests
- Senior loan expert follow-up message for eligible customers
